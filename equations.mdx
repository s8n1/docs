# Equation Test / آزمون معادلات

This page is a **documentation test fixture**: each result is shown with intermediate steps so it can be checked by inspection.

## 1. Linear equation / معادلهٔ خطی

**Test:** `2x + 6 = 14`

**Solution:**

```text
2x + 6 = 14
2x = 14 - 6
2x = 8
x = 4
```

**Answer / پاسخ:** `x = 4`

## 2. Quadratic equation / معادلهٔ درجهٔ دوم

**Test:** `x² - 5x + 6 = 0`

Factor the polynomial:

```text
x² - 5x + 6 = (x - 2)(x - 3)
(x - 2)(x - 3) = 0
```

Therefore:

```text
x = 2  or  x = 3
```

**Answer / پاسخ:** `x ∈ {2, 3}`

## 3. Simultaneous equations / دستگاه معادلات

**Test:**

```text
x + y = 10
x - y = 2
```

Add the equations:

```text
2x = 12
x = 6
```

Substitute into the first equation:

```text
6 + y = 10
y = 4
```

**Answer / پاسخ:** `x = 6, y = 4`

## 4. Fraction equation / معادلهٔ کسری

**Test:** `x/3 + 2 = 5`

```text
x/3 = 5 - 2
x/3 = 3
x = 9
```

**Answer / پاسخ:** `x = 9`
